Version scope: these are the existing per-projection 8-row kernels, using previously fixed per-M selections from shared-m1-32-tune. The newer QKV 16-row-reuse optimization has not been tuned/deployed for these three projections. Their boundaries must not be interpreted as limits after equivalent retuning.

CUPTI CUDA graphs, 100ms warmup and two reverse-order rounds of 150 samples, cold and warm L2 separately. Configurations fixed before this independent rerun. Allocation, compilation, initial transformation, host work, CPU references and cache flushing excluded. Humming configs selected in the previous independent tuning pass from default/stage2/no-Stream-K.

All 960 selected-path reference comparisons passed atol=.002, rtol=.02 and relative L2<.001. The only selected case with >10% round-median spread is O M=31 warm (13.1905/11.523 us); both rounds lose and this does not affect the M=25 crossover. Original raw samples are retained.
